# OOP Practice

This repository contains C++ Object-Oriented Programming practice exercises and coursework assignments.

## Projects

| Practice | File | Concept |
|---|---|---|
| P1 | `P1_BANK _SIM.cpp` | Bank account simulation |
| P2 | `P2_MOVIE_TICKET.cpp` | Movie ticket booking |
| P3 | `P3_EMPLOYEE_MANAGEMENT.cpp` | Employee management |
| P4 | `P4_BANK_ACC_OPERATOR_OVERLOADING.cpp` | Operator overloading |
| P5 | `P5_BANK_DMA.cpp` | Dynamic memory allocation |
| P6 | `P6_HR_MANAGEMENT.cpp` | Human resources management |
| P7 | `P7_TICKET_VIRTUAL_FUNCTIONS.cpp` | Virtual functions |
| P8 | `P8_TICKET_POLYMORPHISM.cpp` | Polymorphism |
| P9 | `P9_TICKET_ABSTRACT.cpp` | Abstract classes |
| P10 | `P10_TICKET_EXCEPTION_HANDLING.cpp` | Exception handling |
| Trial | `trial.cpp` | Practice and experiments |

> `P3_EMPLOYEE_MANAGEMENT.cpp`, `P7_TICKET_VIRTUAL_FUNCTIONS.cpp`, and `P10_TICKET_EXCEPTION_HANDLING.cpp` are currently empty placeholders.

## Compile

Compile an individual program with a C++ compiler such as GCC or MinGW:

```sh
g++ "P1_BANK _SIM.cpp" -o "P1_BANK _SIM.exe"
```

Run the compiled program:

```sh
".\P1_BANK _SIM.exe"
```
